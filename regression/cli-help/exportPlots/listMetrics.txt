Usage: mixcr exportPlots listMetrics [--locale <localeOverride>] [--no-warnings] [--verbose]
                                     [--help] input.json[.gz]
List available metrics
      input.json[.gz]      Input file with PA results
      --locale <localeOverride>
                           Override default locale for formatting (e.g. 'POSIX', 'C', 'en_US',
                             'de_DE').
                           Default is 'POSIX'.
      -nw, --no-warnings   Suppress all warning messages.
      --verbose            Verbose messages.
  -h, --help               Show this help message and exit.
