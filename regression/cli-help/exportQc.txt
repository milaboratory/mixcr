Usage: mixcr exportQc [--locale <localeOverride>] [-h] COMMAND
Export QC plots. This command has subcommands, use -h to see more
      --locale <localeOverride>
               Override default locale for formatting (e.g. 'POSIX', 'C', 'en_US', 'de_DE').
               Default is 'POSIX'.
  -h, --help   Show this help message and exit.
Commands:
  align       QC plot for alignments.
  chainUsage  Chain usage plot.
  tags        Tag refinement statistics plots.
  coverage    Exports anchor points coverage by the library.
