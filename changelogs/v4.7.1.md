## ❗ Breaking changes

- Shortcut options `-p` and `-pf` are removed from export commands. They are conflicting with new added export fields
  `-pN`, `-pS` and `-pNpS`

## 🛠️ Other improvements & fixes

- Tracking the progres of fasta[.gz] inputs on `align`.
- Improved alignment rate of short parts of genes in reads with height rate of mutations
- Amplicon presets now keep up to 15 V gene candidates per read mate (was 2) before paired mates are combined. With
  large families of near-identical V genes (rabbit IGKV) the true gene was often dropped for one mate, so the mates
  were not merged and VDJRegion stayed uncovered; rabbit BCR amplicons now give 60% more clonotypes. The final number
  of V hits per alignment is unchanged (5)
- Fixed combination of `-Massemble.sortBySequence=true` and `--assemble-clonotypes-by` with composite feature
- For `findShmTree` command `--alleles-search-could-be-skipped` option is added for special cases
- Added `[withAlignmentGaps]` option to features exports in `exportShmTreesWithNodes` command. That will add gaps, so
  results could be interpreted as alignments of all nodes to root sequence
- Added `-pN`, `-pS`, `-pNpS` options for `exportShmTreesWithNodes` command
- Fixed `findShmTrees` command. Now it outputs root node with the reconstructed NDN region (before it was filled with N
  letters)
- All exports now have vHit, dHit, jHit and cHit columns
- Added default expected chains for all presets
- Fixed tests to ignore lines with warnings that may appear when compiled with the latest Java

## 🧬 Reference gene library changes

- Built-in reference library updated to RepSeq.IO library v6.5
- IG and TR references for new species:
  - Dog (IGH, IGK, IGL, TRA/TRD, TRB, TRG)
  - Pig (IGH, IGK, IGL, TRA/TRD, TRB, TRG)
  - Atlantic salmon (IGH, IGK, IGL, TRA/TRD, TRB, TRG)
- New chains:
  - Chicken: IGL
  - Rhesus macaque: IGK, IGL
  - Cynomolgus macaque: IGK, IGL
  - Rat: IGH, IGK, IGL
- Corrected references: human IGH (`IGHV4-38-2` coordinates), rabbit IGH, IGK, IGL, rhesus macaque IGH (`IGHV3-182`, `IGHV4-86`, `IGHV5-189`) and TRB (`TRBC2`), cynomolgus macaque TRA (`TRAV24`), rat TRA (`TRAV3-4`)
